\### Descrição do Problema

Em uma loja virtual, os clientes frequentemente desejam filtrar os produtos pelo preço. O problema escolhido simula essa funcionalidade. Organizar os preços facilita a visualização para o consumidor.



\### Objetivo da Aplicação

Desenvolver um programa em C que armazene 10 preços desorganizados e aplique o algoritmo Bubble Sort para ordená-los e exibi-los em ordem crescente.



\### Como funciona o Bubble Sort?

O algoritmo percorre o array diversas vezes, comparando pares de elementos adjacentes. Se o da esquerda for maior que o da direita, eles trocam de posição.
